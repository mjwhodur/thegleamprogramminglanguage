# Editors supporting Gleam

Although editor is a very personal choice, there are some editors that support Gleam.

## Free and open source

### VS Code 
- Requires Gleam extension. It can be downladed from Visual Studio Code Marketplace.

The editor can be downloaded from [VS Code website](https://code.visualstudio.com/download)

## Paid / non free

### Cursor
- Requires Gleam extension. It can be downladed from Visual Studio Code Marketplace.

The editor can be downloaded from [Cursor website](https://cursor.com)

Features AI autocompletion. 

Pricing from 16$/month (yearly subscription) or 20$/month.
